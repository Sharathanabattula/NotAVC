Renders the NotAVC wordmark, with "Not" at reduced opacity and "AVC" at full weight, in one of three background treatments.
```jsx
<Wordmark variant="dark" tagline size={40} />
```
Variants: 'light' (ink text, transparent bg), 'dark' (white text on Ink), 'accent' (white text on Signal green). Never use for a real logo file — pair with the SVGs in assets/logos/ for production exports.
