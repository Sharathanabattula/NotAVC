Frosted-dark data table for Reel data-overlays — label/value rows, values color-coded by sentiment.
```jsx
<DataCard rows={[
  { label: 'Fund size', value: '$100M' },
  { label: 'Expected failures', value: '14 of 20', sentiment: 'negative' },
  { label: 'Need from winners', value: '10-50x each', sentiment: 'positive' },
]} />
```
