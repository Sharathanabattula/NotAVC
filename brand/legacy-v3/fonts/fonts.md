# NotAVC — Font Stack

## Google Fonts import URL

```
https://fonts.googleapis.com/css2?family=Montserrat:wght@400;500;600;700;800;900&family=Source+Sans+3:wght@300;400;500;600;700&family=Source+Code+Pro:wght@400;500;600&display=swap
```

## Font roles

### Montserrat (Display)
- **Weights used:** 600, 700, 800, 900
- **Role:** Headlines, stat numbers, brand name, carousel titles, Reel hooks
- **Rules:** Never for body text. Always negative letter-spacing (-0.2 to -0.5px)
- [Google Fonts page](https://fonts.google.com/specimen/Montserrat)

### Source Sans 3 (Body)
- **Weights used:** 300, 400, 500, 600, 700
- **Role:** Body text, descriptions, captions, long-form content
- **Rules:** The readable workhorse. Never bold — switch to Montserrat for emphasis
- [Google Fonts page](https://fonts.google.com/specimen/Source+Sans+3)

### Source Code Pro (Data)
- **Weights used:** 400, 500, 600
- **Role:** Numbers, metrics, valuations, percentages, dates, episode numbers, hashtags, metadata
- **Rules:** This is the "quant" signal. ALL numeric data uses this font
- [Google Fonts page](https://fonts.google.com/specimen/Source+Code+Pro)
