# Template — Reel script (30s, faceless — the default reel length)

```
HOOK   0–3s   — One line, one tension. Number on screen immediately.
CORE   3–20s  — TWO beats maximum. One analogy OR one mechanism, never both.
OVEN   20–26s — The insight nobody else is saying.
CLOSE  26–30s — Question or honest admission. Hold 2s on end card.
```

Rules:
- 30s is the default; use the 60s format only when the concept truly needs 3 beats.
- ~65–75 spoken words total. If the script is longer, cut a beat, not the pace.
- Every reel must be pegged to something current (this week's round, filing, or headline) —
  evergreen concepts get a fresh news peg in the HOOK.
- On-screen text: Plus Jakarta Sans 800; numbers in Space Mono; Luxe Dark #140D10 bg.
