# Template — Reel script (60s, faceless, use assets/faceless-reels.html)

```
HOOK   0–3s   — One punchy line on screen. Key term in Mint/accent.
SETUP  3–15s  — Why this matters. One real-world reference.
CORE   15–45s — The concept in layman terms. ONE analogy. Max 3 beats.
OVEN   45–55s — The insight nobody else is saying.
CLOSE  55–60s — Question or honest admission. Hold 2s on end card.
```

On-screen text: Plus Jakarta Sans 800 for hooks, captions centered.
All numbers in Space Mono. Background #0B0B0B (v2) or Luxe Dark #140D10 (v3).
Same episode number as the day's carousel/post.
