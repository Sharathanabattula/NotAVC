## Font roles

### Plus Jakarta Sans (Display)
- **Weights used:** 600, 700, 800
- **Role:** Headlines, stat numbers, brand name, carousel titles, Reel hooks, logo wordmark
- **Rules:** Never for body text. Always negative letter-spacing (-0.2 to -0.5px). Geometric but warmer than Montserrat — rounder letterforms give a premium, modern feel. Used by Stripe, Linear, Vercel.
- [Google Fonts page](https://fonts.google.com/specimen/Plus+Jakarta+Sans)

### Outfit (Body)
- **Weights used:** 300, 400, 500
- **Role:** Body text, descriptions, captions, long-form content, social post copy
- **Rules:** The clean, geometric workhorse. Highly legible at small sizes on mobile. Never bold Outfit — switch to Plus Jakarta Sans for any emphasis. Weight 500 max.
- [Google Fonts page](https://fonts.google.com/specimen/Outfit)

### Space Mono (Data)
- **Weights used:** 400, 700
- **Role:** ALL numbers, metrics, valuations, percentages, dates, episode numbers, hashtags, metadata, brand labels
- **Rules:** Fixed-width = instant "quant" signal. More distinctive character than Source Code Pro. Use for any data that should feel intentional and precise.
- [Google Fonts page](https://fonts.google.com/specimen/Space+Mono)
